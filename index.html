Tiwut Terminal Emulator

The Tiwut Terminal is a command-line emulator written in Python, leveraging the powerful `cmd` and `rich` libraries to provide a robust and visually appealing terminal experience. It's designed to manage files and directories within a dedicated root folder: ~/Documents/TiwutApps.

💻 Features

The terminal supports several common file system operations, allowing users to navigate and manipulate files within a contained environment.

📋 Available Commands

Here is a list of the core commands supported by the Tiwut Terminal, offering functionality similar to basic Unix-like shell commands:

  • pwd

    Prints the Path Working Directory (the current directory path).

  • ls [path]

    Lists the contents of the current directory or the specified path. It displays the type (DIR, FILE, EXE), name, and size.

  • cd <directory_name> | cd .. | cd

    Changes the current working directory. Use cd .. to go up one level, or cd without arguments to return to the root (~).

  • mkdir <directory_name>

    Creates a new directory.

  • rmdir <directory_name>

    Removes an empty directory.

  • rm <file_name> | rm -r <directory_name>

    Removes a file. Use the -r flag to recursively remove a non-empty directory (use with caution).

  • cp <source> <destination>

    Copies a file or a directory (recursively).

  • cat <file_name>

    Displays the content of a text file. It includes a safeguard for very large files.

  • help | ?

    Displays help information for commands.

  • exit | quit | EOF

    Exits the Tiwut Terminal.

⚙️ Technology Stack

The terminal is built using:

  • Python: The core programming language.
  • cmd module: Provides the basic framework for the line-oriented command interpreter.
  • rich library: Used for creating beautiful, colored, and formatted terminal output (tables, stylized text, etc.).
  • pathlib module: For object-oriented file system paths, improving code readability and robustness.

ℹ️ Installation and Usage

To run the Tiwut Terminal, you must have Python installed and the rich library. The terminal ensures a clean operating environment by containing all operations within the ~/Documents/TiwutApps directory.

Prerequisites:

pip install rich

Execution:

Save the provided Python code as tiwut_terminal.py and run it from your standard terminal:

python tiwut_terminal.py

The terminal will greet you and be ready to accept commands.
